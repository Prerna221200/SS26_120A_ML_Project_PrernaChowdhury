# Road Damage Detection Using CNNs

Student: Ravi Ansh

This repository contains the Phase 2 proposal and implementation for road damage detection using CNNs.

## Dataset
Recommended Kaggle dataset: https://www.kaggle.com/datasets/sabidrahman/pothole-cracks-and-openmanhole

Classes: pothole, crack, and open manhole.

## Models
- Custom CNN
- MobileNetV2 transfer learning model

## Outputs
The notebook saves:
- Class distribution chart
- Sample images
- Accuracy and loss curves
- Confusion matrices
- Classification reports
- Model comparison CSV
- Saved Keras models

## How to Run
1. Open the notebook in Kaggle.
2. Add the dataset using Add Input.
3. Run all cells from top to bottom.
4. Download outputs from `/kaggle/working/outputs`.
